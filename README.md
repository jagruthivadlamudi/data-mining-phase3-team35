Step 1:
Open terminal and navigate to the project folder

Step 2:
Run the Python file

python3 data_mining_project.py

Step 3:
The cleaned datasets, metrics, and graphs will be generated automatically inside the output folder.

## Project Summary

This project analyzes salary transparency policies and workforce diversity metrics in the technology industry using data mining techniques. The project applies a Flag-First Data Cleaning Framework to preserve data integrity while identifying salary gaps and diversity trends.
